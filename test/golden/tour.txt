# The tour

This document shows every element mdv supports in its first version, starting
with the front matter above, which is shown as written. A paragraph runs long
enough to wrap at the measure, so you can see how soft breaks join into a single
flowing line, and how the right edge settles.

A line can end in a hard break
like this one, or with two trailing spaces
like this.

## Inline

Text can be emphasized, strong, both, struck through with two tildes or one, or
`code`. Escapes keep *literal* stars, and entities such as © & — decode. Raw
<kbd>inline html</kbd> is shown as written.

A link with a title (https://commonmark.org), a reference link
(https://spec.commonmark.org/0.31.2/), a relative link (manual.md) whose path
follows it, an autolink https://ziglang.org, an email hello@example.org, and an
image [image: a small diagram] (diagram.png).
